# AGENTS.md — PromptExtract

Extracts the final positive prompt from PNG images generated by ComfyUI (with fallback to A1111/Forge/SD.Next-style images). Analyzes PNG metadata, follows the graph to the last `CLIPTextEncode` node feeding the sampler's `positive` input. Single Python script, Pillow-only dependency, outputs to .txt or .csv. Python 3.10+.

## Architecture in 60 seconds

- **Single script.** `extract_prompts.py` contains all logic — no modules, no package structure.
- **Three metadata sources (tried in order):**
  1. `workflow` chunk — the visual ComfyUI graph (works with ShowText, direct CLIPTextEncode inputs, linked string chains)
  2. `prompt` chunk — the flattened API graph ComfyUI actually executed (handles subgraphs, reroutes, API-generated images)
  3. `parameters` chunk — A1111/Forge/SD.Next plain-text metadata (positive prompt up to `Negative prompt:` / `Steps:`)
- **Graph traversal.** Finds the last CLIPTextEncode node that feeds the `positive` input of the sampler that created the saved image.
- **Handles edge cases:** direct text in CLIPTextEncode, linked string nodes (ShowText, concatenators), subgraphs (already expanded in prompt chunk), reroutes.
- **CSV output sanitized** against spreadsheet formula injection.
- **Deterministic** (alphabetical) processing order, per-file skip reasons, summary count.

## Build / test / run

```bash
# Install dependencies
pip install -r requirements.txt

# Run (current folder)
python extract_prompts.py

# CSV output
python extract_prompts.py --csv

# Custom input folder
python extract_prompts.py "C:\path\to\images"

# Custom input + output
python extract_prompts.py "C:\path\to\images" "C:\output\my_prompts.txt"
python extract_prompts.py "C:\path\to\images" "C:\output\my_prompts.csv" --csv

# Recursive scan
python extract_prompts.py --recursive

# Windows quick start: drag a folder onto extract_prompts.bat

# Run tests
pytest
```

## Conventions & gotchas

- Single-file tool — `extract_prompts.py` is the entire feature. Keep it self-contained.
- Pillow is the only dependency. No torch, no ComfyUI installation needed.
- Defaults to current folder for both input and output.
- CSV prompts are quoted (commas and newlines preserved). Formula injection is sanitized.
- Skip reasons are reported per-file (no metadata, no sampler found, etc.).
- Tested on Windows 11 with Python 3.10+.
